# 乡村课堂 AI 助教示范方案

本文档用于比赛演示和后续试点，不把尚未发生的试点结果写成事实。当前仓库中的效果数据只能作为系统技术验证，真实学校数据需要在获得学校和教师同意后采集。

## 示范场景

以一所乡村小学或初中为对象，选择一名教师、一间普通教室和一个知识点，完成“课前备课 → 课堂播放 → 学生提问 → 课后复习”的最小闭环。

首选演示主题：

- 八年级物理《能量守恒定律》：山路骑行、水电站、摩擦发热。
- 八年级数学《勾股定理》：操场测量、屋架和田地直角距离。
- 七年级语文《诗词意象》：月亮、炊烟、归雁等熟悉景物。

## 产品闭环

1. 教师选择学科、年级、章节和教材版本，载入乡村课堂备课模板。
2. 教师通过 AI 助教询问定义、易错点、生活化例子和随堂小题。
3. 平台生成分镜、配音和教学动画；勾选低带宽优先时默认采用轻量渲染配置。
4. 教师在课堂播放页进行大屏播放，也可以课前下载视频后离线使用。
5. 学生问题回到 AI 助教，回答展示知识点来源，教师负责最终判断。

## 试点记录表

| 项目 | 记录内容 |
|---|---|
| 学校/班级 | 只记录经授权的必要信息，不公开学生姓名 |
| 教材版本 | 人教版、部编版、北师大版或校本教材 |
| 课前耗时 | 教师从输入知识点到拿到可用材料的分钟数 |
| 网络条件 | 在线、间歇网络、完全离线播放 |
| 课堂使用 | 播放时长、暂停提问次数、教师修改次数 |
| 学习反馈 | 课前/课后同一组小题正确率变化 |
| 教师反馈 | 节省了什么工作，哪些回答需要人工修正 |
| 内容安全 | 是否出现事实错误、超纲内容、隐私或不适当表达 |

## 参赛演示建议

- 先演示教师提问，再展示知识点来源和本地兜底状态，证明网络不稳定时仍可工作。
- 再用同一个知识点载入备课模板，展示教材版本、课堂场景和低带宽配置如何影响生成任务。
- 最后进入课堂播放页，展示全屏、暂停、下载离线视频和回到 AI 助教追问。
- 不把“预计节省时间”或“提升正确率”当成真实成果，除非已有授权的试点记录。
## 产品内试点记录流程

平台左侧新增“试点记录”页面，教师可直接完成以下证据闭环：

1. 从“我的课程”选择已生成课程，自动带出课题、学科和年级。
2. 填写真实学校、地区、教师、班级和教材版本；公开材料应对学校和教师姓名脱敏。
3. 记录使用平台前后的备课分钟数，系统汇总平均节省分钟数和节省率。
4. 填写同一批学生的课前/课后小题总数与答对数，系统计算正确率和变化值。
5. 教师按 1-5 分评价 AI 回答准确率和可用性，并写明需要人工修正的内容。
6. 记录网络状态、是否提前下载、是否实际离线播放、播放时长、中断次数和现场异常。
7. 勾选授权与隐私确认后提交；管理员可将材料标记为“已复核”。

### 自动记录与人工填写边界

- 系统自动计算：备课节省分钟/比例、前后测正确率、正确率变化、评分平均值、网络状态分布、离线播放记录数。
- 教师人工填写：真实学校与课堂背景、使用前备课时长、学生小题统计、AI 回答评价、现场异常说明。
- 当前系统不自动判断试点真实性；“已复核”表示管理员已对授权材料或原始记录进行人工核验。
- 未提交或缺少有效分母的记录不进入效果汇总；没有真实数据时页面明确显示“暂无真实试点数据”。

### 建议保留的原始证明材料

系统记录用于结构化统计，比赛附件仍建议由学校或教师线下保留：授权确认、备课计时截图、匿名化答题统计表、教师签字反馈、低带宽或离线播放照片/视频。不要上传包含学生姓名、正脸、身份证、联系方式的材料，除非已取得适当授权并完成脱敏。
